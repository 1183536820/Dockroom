# 渡柜 · 两台 Windows 电脑页面接入

将同一个 `Dockroom-Windows-x64.exe` 复制到两台 Windows 电脑并双击。不需要终端命令、第二种 EXE、手填另一台主机 IP、传证书或编辑 JSON。运行 Windows x64，推荐 Edge / Chrome。先在同一局域网或 VPN 内用合成文件试用。

1. 主机：在「让其他电脑加入」选实际局域网地址，不选「仅本机（测试）」。第一次设管理员口令，点「开启主机」→「生成连接码和密钥」。分别复制两项，只发给可信的人。`DG2.` 开头的连接码可长期复用，密钥只在生成或更换时显示，请妥善保存。
2. 另一台：在「连接其他电脑」粘贴连接码和密钥，选择「新建专用收件夹（可收发）」或点「选择文件夹」开放一个已有 NTFS 文件夹（只读），然后点「连接主机」。在线后自动进入双栏，不需要再批准或登录主机账号。
3. 主机点「打开本机双栏」，加入端点「打开已连接主机双栏」。如果同一台电脑兼任两个角色，两个入口始终分开，不会因为本机主机也在运行就跳到错误的工作台。主机默认已有「本机收件夹」，不用自己再配对；曾被明确撤销的收件夹不会自动恢复。通过「共享文件夹」选择目录，选中文件按 Ctrl+C，再到另一栏按 Ctrl+V 并确认。

看不到想要的目录？在存放该目录的电脑上点「添加本机文件夹」，可以逐个添加多个目录，不用到权限页再授权。在同一页面有真实路径，以及「在资源管理器打开」按钮。新添加的现有目录不修改原 ACL，只有通过写入检查才会标「可粘贴」；否则可作为复制来源，收件请选专用收件夹。新版另一台电脑只看到本机和主机已开放的目录，不看到其他来访设备，也不开放整块磁盘。

如果连不上：两台电脑须能互访；主机 TCP 8442/8443（可在高级设置更换）仅向可信局域网/VPN开放。若 Windows 防火墙阻挡，请让管理员只放行私有网络上的主机监听端口；被连接端不用开放入站端口。不支持通过接入码穿透公网或防火墙。现有文件夹保持只读，默认专用收件夹通过原有 NTFS 写入检查后才允许写入。

已接入的电脑下次打开程序自动重连，无需再填两项；自己的设备证书会自动续期。主机可在「设备管理」更换密钥或停用新设备接入。它们不影响已接入电脑；如需断开某台电脑，单独执行「撤销设备」。如发现密钥泄露，应更换密钥并检查、撤销陌生设备。旧 `DG1.` 一次性码兼容旧审批流程。

在「连接设置」内，「重新连接」沿用已保存的身份，不用重新输码；「更换主机」输入新的连接码和密钥，原来开放的文件夹保留，新连接未成功保存时不会断开旧连接。设备连通、双栏不可用和无可用共享文件夹是不同状态，页面会分别提示。

关闭页面不停止后台。若要停止，请在「本机连接设置」点「退出渡柜」。重启程序时可用页面启动已有主机。当前安装仅支持一个保存的文件端身份。主机 IP 或 CA 变化需重新配置。EXE 为无数字签名的试用构建；文件清单给出 SHA-256，不等同于正式发行签名。
