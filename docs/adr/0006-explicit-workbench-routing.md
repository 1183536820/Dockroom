# ADR 0006 · 本机主机与已连接主机分开打开

同一个启动器可以同时开主机和连接另一台主机。原本 `/` 只会在没有本地主机时走远端；设备通道在线不能证明正在看的工作台属于该连接。现在本机主机保持 `/`，已连接主机固定 `/connected/`，前端请求和剪贴板、任务、目录恢复都在当前工作台上下文内。远端工作台页面资源使用 EXE 内置文件，只有白名单文件操作 API 会经既有 mTLS 会话转发。断线或撤销不向本机主机回退。

连接状态分开检查控制通道和远程工作台的授权目录；无共享目录或远程工作台不可用时显示原因和操作入口。重连沿用存储身份，更换连接用新码重新建立独立身份，成功保存后再替换运行实例，失败保留原连接。更换连接明确使用原来开放的文件夹，不删除原文件、身份目录或任务。不得自动恢复已撤销的本机收件夹。
