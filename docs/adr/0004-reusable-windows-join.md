# ADR 0004 · 可复用的连接码与独立共享密钥

用户要求以预先分发的共享密钥批准新设备，取代新版 Windows 流程的逐台人工批准。接入码 `DG2` 只携带 Hub 地址、设备端口与公开 CA，不含凭据、设备编号或到期时间；单独生成 256 位随机密钥，Hub 只存其摘要。TLS 验证保持不变；首次接入走 HTTPS。旧一次性码与人工确认保留兼容。

只有管理员可以启用、轮换或停用免审批。持有两项的电脑能注册新的独立身份，首次上线只给启用该密钥的管理员授权该设备主动开放的 `files` 根，写权限仍由本机探测决定；不反向授予其他根或工作台权限。授权只发一次，后续撤权不会在重连时自动恢复。生成时展示密钥一次，遗失可轮换。轮换/停用只影响未来入网，撤销已接入设备需单独处理。密钥泄露后同时轮换和撤销陌生设备。

日常重连与续期使用每台设备各自保存在本机的私钥，不保存共享密钥。续期使用已登记公钥对应的签名 CSR 和已验证的 Hub TLS；复用尚有有效期的签发结果以免重复续期打断设备，撤销后拒绝续期。此改动不扩大 Windows 文件引擎的能力范围。
