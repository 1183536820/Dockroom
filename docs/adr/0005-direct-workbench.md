# ADR 0005 · 连接后直接操作文件

保留文件引擎、TLS、身份钉住、用户主动开放的目录以及撤权。简化配置：桌面主机自动登记一个独立的本机收件夹，配对后工作台可直接选择两台电脑。每台电脑可在本机设置追加多个目录，无需再给主机人工授权；新增根自动授权只发生一次，不会恢复撤销的授权。已有目录默认不修改 ACL，只有通过原 NTFS 写入策略才能作为写目标。不会共享磁盘根、程序状态、或绕过原路径校验。

已用 DG2 配对的另一端也能打开双栏：其本机进程向 Hub 专用 mTLS 监听请求受限会话，工作台请求由受本机能力保护的回环服务经固定且证书验证的 Hub HTTPS 地址转发。设备会话不是管理员，只能访问该设备与桌面主机主动开放且仍在授权中的目录，不能看到其他客户端、连接密钥或设备管理。文件数据仍由原 Agent 数据通道传输，不转发给浏览器。旧 DG1 和 CLI 主机保留原流程。
