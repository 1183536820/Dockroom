# ADR 0003 · Windows 用一个 EXE 的本地页面配对

同一 Windows EXE 双击启动本机管理页，可开主机或运行 Agent；可在一台电脑同时运行两种角色。远端需能到达 Hub 的 LAN/VPN 地址。现有 HTTPS/mTLS、一次性接入、手动核对与授权根语义不变。

接入码 `DG1.<base64url>` 携带明确的 Hub 地址、设备端口、预留设备 ID、到期时间、256 位一次性凭据和公共 CA DER。代码由登录的 Hub 管理员颁发，另一台仅从可信联系人复制接入码。客户端用它提供的 CA 验证 TLS 主机名和链，不关闭验证，不跟随重定向；不上传本机密钥，不把码放在 URL、配置或日志。主机名/证书变更重发。没有发现、中继服务或公网穿透。

本机页面只绑定随机回环端口，使用单次安装独立的 `.localhost` 主机名，启动链接用 fragment 交付随机本地能力，交换为 HttpOnly/SameSite/Secure cookie；校验 Host、Origin。受该能力保护的本机工作台调用同一 Hub 浏览器处理器（只换本机 Origin），保留 Hub 用户认证及 CSRF；局域网入口仍是 HTTPS。这避免本机管理员修改系统信任。局域网 Host 或端口不可用由 UI 报错，不自动开防火墙。自有状态与凭据限当前 Windows 用户、SYSTEM、管理员。默认只读共享；写入仅在同卷私有区/ACL 通过原有检查后启用。
