# ADR 0002 · Windows 优先验收

用户调整首个可用目标为 Windows/NTFS。Windows 双 Agent 的实际数据、安全、恢复门槛仍必须通过；Linux 只要求对本轮改动保留构建和契约，Linux 实机与写入授权不计入本轮通过。

M2 保持设备 WSS 控制和 mTLS HTTPS GET/PUT 直传协议。首次接线使用单个持久调度 worker、单普通文件及默认跳过，后续再扩大并发和批次。写根要求本机显式准备并钉住同卷 `.dockroom`，校验 Windows 目录 ACL，仅接受专用服务账号、SYSTEM 和本地 Administrators 的允许 ACE。M2 目标父目录须匹配私有区的可继承文件 ACL；不声称支持任意复杂安全描述符。其余平台和未准备的根只读。文件发布须以句柄相对独占重命名，恢复须核对持久 intent、文件身份和摘要；测试进程中止，不把测试扩大解释为掉电保证。

替代验收在独立回环 Windows Agent 和真实 NTFS 夹具执行，报告为该环境通过，不替代独立主机、网络或服务账号安装验收。目录树及文件维护仍属 M3，不提前开启。
