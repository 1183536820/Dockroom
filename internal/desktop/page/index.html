我的电脑 · 浏览磁盘

打开本机双栏

这台电脑的共享文件夹

双栏里选中对应电脑，再选这里列出的文件夹。专用收件夹可直接粘贴；新增的文件夹若不适合写入会标为只读。

    01 / HOST

    让其他电脑加入

    生成连接码和密钥，只发给可信的人。使用新版密钥连接后，可直接读写当前 Windows 用户能访问的本机磁盘文件。

    高级设置：端口

    ● 主机已开启

    02 / JOIN

    连接其他电脑

    粘贴主机发来的连接码和密钥，连接后即可在双栏中浏览磁盘和收发文件。不用输入 IP，也不用拷贝证书。

    开放本机哪个文件夹？

    将原来开放的文件夹改连新主机；新连接成功保存后，才断开旧连接。文件不会被移动或删除。
